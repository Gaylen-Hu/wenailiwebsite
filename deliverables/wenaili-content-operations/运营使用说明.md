# 奈李官网新闻与案例运营技能包

版本：2026-09-22。交给运营时发送整个 ZIP，不要只复制 SKILL.md；references、assets、scripts 都需保留。本包不含任何真实密钥，不会自行连接或发布文章。

## 1. 安装到 OpenClaw

解压后，将 `wenaili-content-publisher` 整个文件夹复制到运营当前 OpenClaw agent 的工作区 `skills` 目录，形成：

```text
<当前工作区>/skills/wenaili-content-publisher/SKILL.md
<当前工作区>/skills/wenaili-content-publisher/references/...
<当前工作区>/skills/wenaili-content-publisher/assets/...
<当前工作区>/skills/wenaili-content-publisher/scripts/...
```

使用默认工作区时通常是 `~/.openclaw/workspace/skills/`；有多个 agent 或自定义工作区时，以该运营 agent 的实际配置为准，不能只放进任意下载目录。打开新会话并让它读取这个技能；可用 `openclaw skills list` / `openclaw skills check` 检查加载情况。存在同名旧版本先备份、再替换，避免混用。

安装方式依据 [OpenClaw 官方 Skills 文档](https://docs.openclaw.ai/tools/skills)。技能是说明书，不会自动安装图片处理、浏览器、HTTP工具或授予网站权限。

## 2. 管理员一次性准备

- 明确目标域名、测试/生产环境、默认语言 zh，以及谁有权批准发布。
- API 模式：通过受控的运行环境/秘密管理配置 `WENAILI_BASE_URL`（站点 HTTPS origin）和 `WENAILI_API_KEY`（对应服务端 NEWS_API_KEY 的值），确保实际执行 HTTP 的工具进程可读取。不同 OpenClaw 部署环境注入方式不同，由管理员按实际运行方式配置，不把凭据发进群聊/技能文件。
- **当前项目 NEWS_API_KEY 的角色是 admin，不是新闻专用的最小权限 token。** 不愿授予此权限时先用后台有权限的运营账号；如需受限 API，要由开发另行实现，不能只改 token 名称就认为受限。
- 后台模式：给运营提供有权操作新闻/案例的账号和已登录浏览器。技能不会绕过登录/验证码/编辑锁。
- 需要网页预览、图片查看/压缩能力；没有这些工具就让人工完成对应检查。Python 3 用于可选离线检查，Pillow 可选用于图片像素检查，无需连接网站。
- 第一次只上传一篇授权的测试草稿，核对媒体上传、字段、预览和权限；通过后再正式批量使用。本交付未用生产接口创建测试文章。

## 3. 给 OpenClaw 的指令示例

新闻草稿：

> 使用 wenaili-content-publisher 技能。根据我提供的资料和来源，为奈李官网写一篇中文物流资讯。目标站点为管理员配置的站点。先核实事实并准备不含密集文字的封面，上传后只保存草稿，不发布。给我草稿ID、预览入口、TDK、图片尺寸体积和检查结果。缺少可靠事实就告诉我，不要编。

客户案例：

> 使用 wenaili-content-publisher 技能。以下是已确认可公开的项目材料和图片授权。创建一篇技术服务案例；客户名称可公开/需按提供的方式匿名。只使用材料中有证据的结果，没有数据不要虚构增长率。先保存草稿并让我看手机和桌面预览。

确认后发布：

> 我已检查草稿ID【实际ID】的当前版本和封面，允许在【目标站点】立即发布这一篇。发布后用未登录视角检查详情、列表、图片和TDK，回报实际链接和状态。不要发布其他草稿。

定时发布：

> 草稿ID【实际ID】已验收，安排在【具体年月日】北京时间【时分】发布，不要现在发布，不设置自动下架。回读确认排期，报告北京时间和UTC。若不能持续监测，请告诉我到点由谁复核。

## 4. 运营记住这几条

1. 封面建议 1600×900、尽量小于 500 KiB，中心有明确主体；不用密集文字海报。网站会把图片裁成方图/不同宽高，标题放文字字段里，信息图放正文。
2. 服务端整个上传请求最多 10 MiB，并非允许文件恰好 10 MiB；运营建议压到 2 MiB 以下。
3. 正文沿用站点语义样式；不要内联 CSS，不要重复一级标题。后台可用导语、提示框、二/三级标题、清单、图注和表格。
4. 新闻填 excerpt、publishedAt；案例填 summary、company。两种内容不能互换字段。
5. 保存草稿 ≠ 发布；新闻显示日期 ≠ 定时发布；定时成功 ≠ 已上线。排期调度基线每 5 分钟运行，不承诺秒级。
6. 必须检查客户/图片授权与事实来源；没有证据就不编数据或评价。图片上传可能已经公开，秘密素材不能先上传再等审批。

## 5. 包内工具

SKILL.md 是入口；references 是详细规范；assets 是正文与JSON模板（含占位符，不能直接上传）；scripts 是只做本地检查的 Python 工具，不包含网络上传/发布逻辑。

在技能文件夹执行：

```text
python scripts/preflight.py news 已填好的新闻.json --image 封面.jpg
python scripts/preflight.py case 已填好的案例.json
python scripts/test_preflight.py
```

FAIL 表示需修复，WARN 需核对。检查器只覆盖本包 semantic html-content 新建模板，不适用于 PATCH 或所有自定义组件。结构通过仍需来源、授权、真实图片关系与视觉验收。

如项目字段、组件、上传限制、API权限或排期方式发生变化，让维护者更新本包后再用，不让代理自行猜测或改服务器配置。
