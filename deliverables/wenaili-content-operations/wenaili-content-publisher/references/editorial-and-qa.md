# 内容与发布验收

## 新闻

先判断是物流资讯、展会资讯还是公司新闻。外部行业变化不是“公司新闻”；公司实际动态才能写成公司行为。资讯要回答：发生什么、何时何地、证据来源、对目标客户有什么影响、可采取哪些行动。

时效性事实必须查原始/权威来源，记录链接、来源发布时间、事件发生时间和核验时间。区分预测、观点与已经发生的事实。水位、运价、运力、政策生效日等数字需注明地域、时间、单位和口径；不要照抄二手标题、不把局部事件泛化为全行业。不能核验时删去无法证实的细节或停留在明确标注的待核验草稿，不公开发布。

建议标题约 18–32 个汉字，直说主题和读者价值，避免夸张恐吓、“震惊/必看/暴涨百分百”。摘要约 60–120 汉字，概括信息和适用对象，不等于重复标题。正文一般约 600–1500 汉字，随内容调整；不以字数为发布门槛。适当用背景、影响、建议清单、来源链接结构，短消息不强凑章节。

## 案例

先确认客户可公开名称/匿名方式、服务范围、项目周期、已完成交付、数据证据、展示素材权限。公开案例应明确“客户问题 → 我们实际做了什么 → 得到什么有证据的变化”。不要把计划、行业平均值、预测收益写成真实成果。

results 的 value 可以写有证据的定性结果。无准确数字时写实际交付物及可核对效果，不能凭空写“提升 300%”。数字说明比较周期、样本、统计口径；客户评价须有原话与授权，不替客户编引语。未公开客户可以在授权后写匿名描述，不能暗示不存在的头部合作。

案例一般约 800–1800 汉字，可按项目复杂度调整。summary 建议 80–150 汉字。CTA 指向实际存在、符合本项目的咨询入口；不要写未经确认的电话/微信/承诺。

## TDK

- T：seoTitle，准确主题，可适度加奈李品牌；建议总长约 25–40 汉字，避免所有文章相同。不是 SEO 排名保证。
- D：seoDescription，建议 70–120 汉字，概述对象、核心信息和价值，不能堆砌关键词。
- K：seoKeywords，3–6 个高度相关词，英文逗号分隔。本项目要求填写，但不承诺关键词标签带来排名。
- title、摘要、TDK 与正文事实一致。前台可能附品牌后缀，实际检查 head 防止品牌重复、多个 title 或错误默认描述。
- 正文来源链接写有意义的名称；不要抄整篇文章或未经许可搬运图片。

## 发布前清单

| 检查 | 通过条件 |
| --- | --- |
| 范围 | 站点/环境/语言/类型/动作明确，未触碰其他文章 |
| 事实与授权 | 客户、数字、日期、引语、图片都有依据；无敏感资料 |
| 字段 | 分类正确、摘要字段正确、封面关系有效、TDK 完整 |
| 正文 | 无占位符/内联 CSS/重复 h1，清洗后关键内容仍在 |
| 图片 | 不模糊、无拉伸、无裁切文字、无破图；alt/图注合理 |
| 桌面 | 约 1440px 视口，详情标题层级、段落、表格和列表正确 |
| 手机 | 约 390px 视口，文字可读、无整页横向溢出；宽表格仅自身滚动 |
| 列表 | 新闻热门方形缩略图及主列表/案例列表看得清主体 |
| 链接 | 外部来源、CTA 和媒体链接实际能打开；readUrl 不误导跳转 |
| 状态 | 保存/已发布/已排期分清，日期与时区正确 |

浏览器视觉检查截图保存在任务交付中，不上传为文章素材。无查看能力时写“待运营验收”，不是“通过”。预览通过后若正文/封面再次实质更改，应重看受影响部分。
